About Us

This website is a collection of small daily puzzles, similar to Wordle and other daily games.

While taking courses in algorithms/computer science, I noticed that some questions including NP-hard problems were surprisingly fun to solve by hand. Furthermore, the idea of reduction between problems can allow a lot of depth to the daily puzzles (although it may feel a bit forced.)

HillClimb is another daily game that is less about solving a problem but exploration. The name, of course still references a classic algorithm.

HardMode is an independent project, improved with help from player feedback.
